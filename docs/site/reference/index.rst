API reference (proof of the Breathe pipeline)
==============================================

This page is the doc-site P1 proof that the Doxygen-XML -> Breathe -> Sphinx chain
is wired end to end: the class below is pulled live from ``build/doc/xml``
(generated by ``doxygen Doxyfile``, P0's ``GENERATE_XML``), not hand-transcribed.
A full API reference is out of scope for this wagon (see the doc-site fiche, P2-P4).

.. doxygenclass:: real::basic_regex
   :project: real

``basic_regex``'s own Doxygen comment ``\ref``-links four related symbols
(``real::regex``, ``real::static_regex``, and the two ``Storage`` policies,
``real::detail::dynamic_storage`` / ``real::detail::static_storage``) that this
single proof page does not itself render -- rendering their concrete,
template-instantiated signatures pulls in ``real::fixed_string`` / ``real::flags``
/ the ``real::detail`` namespace transitively, out of scope for one proof page
(a full API reference is P2-P4, see the doc-site fiche). See ``conf.py``'s
``nitpick_ignore`` for the four resulting Breathe cross-reference labels.
