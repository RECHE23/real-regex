# v2026.7.46 — Inner-literal via alternation-flush (StatusLine, issue #3)

Closes a further slice of the StatusLine gap from
[issue #3](https://github.com/RECHE23/real-regex/issues/3) by **extending extraction**, not
adding a new prefilter route.

## What changed

`extract_inner_literal` used to **abort the whole walk** on any alternation
(`inner_literal.hpp` — “conservative v1”). For
`(info|error|warn)\s+\d{4}-\d{2}-\d{2}\s+req=[a-f0-9]+` that meant the required
downstream literal `req=` never armed, so search stayed on dense first-bytes
`{e,i,w}` + lazy-DFA.

**P0.1 — pure-literal alternation:** if every branch is a fixed byte run
(`info|error|warn`), flush the current run and **continue** (do not append any
branch bytes). A later unconditional run (`req=`) can then win. The reverse
prefix covers `(alt)\s+\d{4}-…\s+` — already supported by the reverse DFA
(shared under 7.45). A non-literal branch (klass, nested alt, …) still declines.

**P0.2 — mono-byte optional (`s?`) — measured and dropped:** arming URL
`https?://…` on `://` regressed **+65% on x86** (memmem multi-byte loses to the
already-strong v7.45 first-byte/`http`+DFA baseline at ~0.053 ns/B). URL stays
on its v7.45 route (`hints` without `inner_literal`). Principle: **IL wins when
the baseline prefilter is weak, loses when it is strong.**

## Measured (dual-ISA, fixed binaries)

| case | arm64 | x86-64/gcc |
| --- | --- | --- |
| StatusLine | **1.32×** vs route-off | **−58.7%** (4.19→1.73) |
| URL | IL unarmed (P0.2 drop) | flat vs 7.45 (~0.053) |
| email-sparse | flat (7.45 holds) | flat |
| witness `[a-z]+` | — | **−8%** incident |
| wplus / fields | — | +1.3% / noise (accepted) |

**Honest residual:** StatusLine is still far from rust (~1.73 vs 0.117 ms on the
#3 corpus). Closing the rest needs SIMD multi-byte / substring work — a future
arc, not this train.

## Proof

- 0-div: `inner_literal_route_disabled` differential extended for StatusLine +
  unsound trap `(abc|xreq=y)z` → only common `z` is selected.
- full-local-gate 18/18; coverage ≥ 95.7; tsan clean.
- Go binding re-vendored for the engine + version bump.

## What this is not

Not a new prefilter route. Not URL acceleration (P0.2 dropped by measurement).
Not the SIMD close of the residual StatusLine gap vs rust.
