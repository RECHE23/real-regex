# v2026.10.7 — Unicode lookarounds tested directly, a lighter lazy-DFA miss

**A lookaround over one Unicode class is tested in place**: `\w+(?!\w)`, `(?<=\p{L})`, `(?<!\w)\w+` and every
other lookaround whose body is a single code-point class went through the lookaround sub-simulation, because
the direct test only recognised the two-slot form a byte class compiles to. They now take the direct test:
**−28 to −66 % instructions** on four compilers. **A lazy DFA's cache miss no longer copies its source state.**

## Fixes

- **A one-atom lookbehind recedes at most three continuation bytes** (430d136): the direct test, once reachable,
  would have scanned back to the start of a run of malformed bytes on every position, a quadratic cost; it is
  bounded as the word-boundary test already was, before the direct test was enabled.

## Performance

- **Lookarounds over a Unicode class are tested directly** (430d136). Instructions per count, GCC 13 / GCC 14 /
  clang 19 / GCC 15: `\w+(?!\w)` −36 / −36 / −36 / −34 %, `(?<=\p{L})\d` −64 / −64 / −66 / −64 %,
  `(?<!\w)\w+` −29 / −30 / −30 / −31 %, `\w+(?=\p{Han})` −58 / −58 / −57 / −55 %, `x(?<=\p{L})` −44 / −45 / −44
  / −45 %. Every other row unchanged but `\w+(?=,)` +1.8 % on GCC 15 alone.
- **A lazy DFA's miss reads its source state in place** (eb4b2d3): five miss paths of the forward and reverse
  lazy DFAs copied the state's pc-set into a fresh vector on every cache miss. A cold first count of a 1 000-word
  alternation over 32 KiB of random letters −2.5 % instructions; the steady state unchanged.

## For contributors

- About 90 lines less across the engine headers, net of the new direct test: members and aliases nothing read (2275e66), comments that
  state their constraint without the measurement that found it (2db91a0), target and cold attributes through
  macros (c3da1b5), and the state-capability guards as named concepts (d2f559e). Two build-time refactors of the
  compiler and the parser were reverted (065be56): they emitted identical programs but moved GCC 15's inlining
  of search paths sharing their translation unit.
