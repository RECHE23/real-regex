# v2026.10.9 — How far before a position a match reads

**`basic_regex::left_context()`** gives an upper bound, in bytes, on how far before a position
`match(text, pos)` reads: a lookbehind as far back as it can consume, and `\b`, `\B`, `\<`, `\>`, a line start
and `\A` one code point. A caller that keeps only part of a text, such as a lexer reading it in pieces, keeps
that many bytes before where it matches next and gets the answer it would get on the whole text. SciLex's
streams use it. The engine's matching is unchanged.

## Added

- **`basic_regex::left_context()`** (88d87ea): 0 for a pattern that reads nothing before where it starts, else
  the widest lookbehind plus four bytes. Pinned by a property test that drops the text before
  `pos - left_context()` on fifteen patterns with lookbehinds, word boundaries and anchors, and compares
  every match with the one on the whole text.
