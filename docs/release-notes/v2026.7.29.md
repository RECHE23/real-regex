## API: `real::regex_set` / `RegexSet` (multi-pattern, which-matched)

New public multi-pattern set — **which patterns match the subject at least once** (RE2::Set / rust
`RegexSet` style), not maximal-munch one-winner (`real::dfa` remains the lexer path and is never used
here).

**C++** (`#include <real/regex_set.hpp>`):

- Construction: brace-init `regex_set{"a", "b"}`, `span`/`vector` of `string` or `string_view`, or
  pointer+count. Shared `flags` on every member. **Compile fails the whole set** if any pattern is
  invalid (no silent skip).
- `is_match(text)` — any-match; stops at the first pattern that hits.
- `matches(text)` — construction-order bitset (`vector<bool>`).
- `which(text)` — indices that matched.
- `operator[]` — re-run the member `regex` for captures after a set hit.
- Region `pos` / `endpos` like `search`.

**Python** `real.RegexSet` and **Rust** `RegexSet` — same which-matched contract; closes the rust
README line that said multi-pattern was not offered.

**Stage-1 implementation:** N independent `search` walks with **per-pattern early-exit** — never
N × `count_matches` full-scan, never `real::dfa::match`. Already competitive at small N (≤ ~24
patterns on our filter corpus). Supports **bounded lookarounds** that RE2::Set cannot compile (a
confirmed differentiator).

### Honesty

- At large N, N-walks **degrade** (architectural: one pass vs N passes). A **fused single-pass** is
  the path to RE2::Set-class throughput (~450 MB/s on our which-matched filter corpus) — **measured,
  not promised**; that is a separate arc (Stage-2).
- Never « faster than Hyperscan ». Hyperscan is a large-N / streaming reference in another corner of
  the arena; the incumbent for this product shape is RE2::Set.

## API: `count_matches` on Python

The 7.28 notes promised Python for the matching-only counter. This train ships
`real.count_matches` / `Pattern.count_matches` (and region-aware C++ `count_matches(text, pos, endpos)`),
the surface that takes the trailing-LA class+ fast path — unlike `finditer`, which stays pure by design.
