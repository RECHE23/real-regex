# v2026.7.45 — Shared confirm-DFA cache (issue #3 sparse gap)

Closes the largest remaining performance gap on the sparse-with-hits shape of
[issue #3](https://github.com/RECHE23/real-regex/issues/3) — **without** a new
rare-byte prefilter. Profiling showed the cost was not a missing `memchr` on
`@` (IL already arms; `byte_frequency` is already in production; no-match was
already winning): each `find_iter` rebuilt the confirm lazy-DFA (~thousands of
Unicode instructions) while `il_prefix_prog` was already built once per program.

## What changed

1. **Process-wide shared DFA slot** (`shared_dfa_slot`: fwd / rev / IL-prefix reverse)
   keyed by `regex_immutables*`, mutex per slot. Warm once; amortize across every
   iterator on that regex.
2. **`regex_immutables` stays immutable and zero-growth** (no `std::mutex` on the
   struct; constexpr `compile` intact). Address-reuse: `reset_shared_dfas` from
   `call_once`. Hot slot resolve uses a **thread_local** last-hit cache, not new
   members on the immutables.
3. **`confirm_at` → `anchored_end`** on the shared forward DFA (+ onepass extract).
4. **Codegen isolation (x86):** DFA search body lives in
   `try_shared_lazy_dfa_search` (`noinline`), so it cannot bloat `pike_vm::run()`'s
   class-loop neighbor — same shape as the AC fix trail.

## Measured (dual-ISA)

| case | arm64 (Grok) | x86-64/gcc (superviseur) |
| --- | --- | --- |
| sparse `(\w+)@(\w+)` (hits) | 0.69 → **~0.05 ns/B** | **−96.8%** (~31×; reverses vs rust) |
| witness `[a-z]+` | flat | **−8%** (was +6% pre-noinline; now a gain) |
| fields `[^,]+` | flat / gain | **−41%** |
| wplus `\w+` | flat | **+4% residual** (accepted; codegen-luck) |
| URL `https?://[^\s]+` (#3) | — | **−30%** vs 7.44 (gap dented, not closed) |
| StatusLine (#3) | — | **−22%** vs 7.44 (gap dented, not closed) |

**Honest residual:** wplus +4% on x86-gcc only. Well below 7.43's disclosed fields
+39% and 7.36's emoji residual. Do not chase further in this train.

**Not closed by this release:** URL / StatusLine absolute gap vs rust (~14× / ~25×
after the dent). Same class as the old sparse gap — skip filler via a literal
discriminant; that is the next prefilter arc, not this train.

## Proof

- 0-div: lazy-DFA routing differential + full suite (same results as pure Pike).
- `make tsan` + 8-thread shared-regex hammer on IL email (clean).
- full-local-gate 18/18; coverage ≥ 95.7.
- Go binding re-vendored for the engine + version bump.

## What this is not

Not a new rare-byte / memchr prefilter (D0 pivoted: already redundant). Not a full
§A re-stamp of absolute cells. Not the fix for URL/StatusLine vs rust — only a
free dent from shared confirm amortization.
