# v2026.8.17 — the first hour

**The C++ snippet on the front page did not compile, and the `std::regex` drop-in broke on
the first line that prints a group.** Neither defect touches matching: the engine was never
wrong here. Both stopped a newcomer before they ever reached it, which is why they ship
together.

The landing's quickstart compared with `"example"sv`, a literal whose `#include
<string_view>` and using-declaration lived outside the region the page displays. The whole
example file compiled; the four lines a reader copies did not. They now compare with
`"example"` and need nothing else. And `std::cout << m[1]` — the line a `std::regex` user
writes immediately after a match — failed to compile against `real::compat`, because the
compatibility layer defined no stream inserter for its `sub_match`. It has one now, so
"change only the include" means what it says.

## Names and messages a caller can act on

**`match_result::str`.** `m.str(1)` is `m[1]`, under the name a `std::smatch` caller writes
first. It returns a view rather than an owned string — no copy, and the subject must outlive
the result — so an owned copy is `std::string s {m.str(1)};`, with braces.

**A pattern `static_regex` cannot compile now says so in one sentence.** A backreference
produced 358 lines of diagnostics, the reason buried 39 lines in, under one error per
dependent member. A validity check asked before those members are read ends the
instantiation at a `static_assert` that names the three usual constructs and points at
runtime `real::regex` for the exact one: 22 lines, the message first, measured under Clang.
The check costs one extra compile-time evaluation per `static_regex` — 1706 ms to 1831 ms on
a one-pattern translation unit.

**An unbounded lookaround names its rewrite.** "Use a fixed repeat count" did not tell anyone
that `.*` becomes `.{0,N}`, and `(?=.*[A-Z])` is the shape people arrive with. The message
now prints the rewrite and the 255-byte ceiling on the sub-pattern, and the test compiles the
advised form on that same password shape, so the advice cannot rot into an encouragement.

**Every binding names its own way out, and only where one exists.** Python appends the
compatibility contract and `fallback=True` to an unsupported pattern's error — not to a
syntax error, which `re` rejects too, and not from `RegexSet`, which has no such policy. The
classification comes from the engine's `error_kind`, never from matching the message text.
C++ has no message suffix to spare, so `error_kind`'s own documentation and the
"Rejected by design" section carry the pointer to `real::compat::regex` with
`policy::fallback`. Rust is deliberately absent from that sentence: its fallback delegates to
the `regex` crate, which refuses a backreference exactly as REAL does.

## Python surface

`repr(real.compile('a', real.I))` read `real.compile('a', re.IGNORECASE)` — two modules in one
expression, so it evaluated in neither namespace. Both halves say `real.` now, and
`eval(repr(p))` rebuilds the pattern. A delegated pattern's repr carries `fallback=True`, the
one place a log shows that this pattern runs on backtracking `re` and has given up the
linear-time guarantee.

`real.PatternError` exists, as an alias of `real.error` rather than a subclass, so code
written against CPython 3.13's spelling catches what the older one raises.

## Go says what it offers

The Go drop-in page is headed **v0.1 subset**, not "Full drop-in". The binding exposes nine
methods and byte-index accessors; the list two paragraphs below the heading was always
accurate, and the heading now agrees with it.

## Guarantees this release adds to itself

Three checks exist because this release's own defects walked past the ones already there.
`check-quickstart-displayed` compiles the region the landing shows as its own translation
unit — compiling the whole example file never proved a paste would build. `make
check-workflows` runs `actionlint` over `.github/workflows` in the preflight, where nothing
had ever read them: a key that Actions rejects at dispatch used to land after a push. And
every job that can carry a ceiling declares `timeout-minutes`; without one a step that never
returns holds a runner for six hours instead of going red. Four jobs still cannot carry one —
GitHub forbids it on a job that calls a reusable workflow — and that limit is written where a
reader will look for it.

One published justification was withdrawn rather than defended. The benchmark baseline's
compiler was said to be "the same g++ 13.3 that builds the manylinux wheels"; the wheel for
2026.8.16 was built by GCC 14.2.1, read out of its `.comment` section. The rule the clause
supported stands on its measured spread, which is all it ever needed. The tables stay stamped
2026.8.15 with their own declared reason: there is no correspondence left to restore, so a
newer compiler is not a reason to re-measure.
