# v2026.10.6 — Walks that build no end sentinel, bindings that cross once, Unicode scans that keep their inlining

**A range-for over `find_iter` no longer zero-fills a whole iterator to build `end()`**, and the library's own
walks (`replace`, `split`, `find_all`, the C ABI, the Python scans) no longer build one at all: on a 30-byte line
with two matches, `replace` 360 → 236 ns and a user's range-for 281 → 178 ns. **The Python binding crosses with
fewer calls and copies**: vectorcall frames for every scan, `sub` keeps its last template parsed, module
functions find a compiled pattern first. **The Go and Rust bindings stop copying what they only read.** And the
trailing-lookaround route over Unicode classes, new in v2026.10.5, **no longer costs the Unicode class scans
that never take it**.

## Fixes

- **Python: a strided bytes-like replacement template is accepted, as `re` accepts it** (8cd830b):
  `sub(memoryview(b)[::2], …)` raised `TypeError`. The group-name caches keep the first of two racing fills.
- **Python: a bytes pattern takes any bytes-like replacement** (a77da23): a `bytearray` or `memoryview`
  template, a callable returning one, and `Match.expand`'s template raised `TypeError`; `re` accepts them.

## Performance

- **`end()` is built without zero-filling the iterator** (47bca2c): its `return {}` value-initialized a
  defaulted constructor, a memset of the whole object, VM state included. `end()` 119 → 25 ns; a range-for over
  a 30-byte line with two matches 281 → 178 ns (Apple clang, arm64). Instructions on the 21-row duel −0.5 to
  −6.3 % on every row.
- **The library's own walks test `exhausted()` instead of comparing with `end()`** (575b9f3): `replace`
  360 → 236 ns, `split` 390 → 256 ns, `find_all` 427 → 290 ns, compat `regex_replace` 363 → 242 ns on that line.
- **The trailing-lookaround route stopped charging rows that never take it** (e5004a4, 6f6c806): the
  code-point walk added in v2026.10.5 had made GCC stop inlining a membership test into the Unicode class
  filler (`\p{sc=Han}+` +3.8 / +9.0 / +2.8 % instructions on GCC 13 / 14 / 15), and made each lookahead match
  two calls (`[a-z]+(?=[a-z])` through `find_iter` +5.2 % on Apple clang, judged real in a layout-robust
  A/B). Both are back: the Unicode rows count their earlier instructions, and the lookahead row is
  indistinguishable from layout on arm64 and −15 % on x86-64 (GCC 15).
- **std::regex compatibility layer**: `it != std::sregex_iterator()` inlines its comparison (3cddd3f), 17.0 →
  14.4 ns per step on Apple clang; `regex_token_iterator` keeps only a split's suffix across a step (1a10c43),
  −17 to −27 % instructions per walk, 754 → 434 µs for a split over 100 KB; RE2 `Replace` and `GlobalReplace`
  append views and allocate nothing on a miss (9f396d4).

## Bindings

- **Python.** `findall`, `finditer`, `count_matches`, `split`, `sub` and `subn` take vectorcall frames
  (925da4b, 08bd7ab): −6 to −12 % per call. `sub` keeps its last template parsed (a77da23): a rich template
  507 → 264 ns per call without a match. Module functions read a dict of compiled patterns first (f2e24b8):
  `real.search(p, s)` 311 → 249 ns. A `sub` that replaces nothing copies nothing (d89159c). `Match.span` and
  `regs` build their pairs directly (55f1ac8), a non-ASCII match's first span read allocates nothing (1bad193),
  `groupdict` 311 → 145 ns and `groupindex` 248 → 69 ns (1228797).
- **Go.** String queries read the string in place instead of copying it (72f8184): `MatchString` over 1 MiB
  with a match at 0 55.1 µs → 66 ns, a short `MatchString`, `Match` or `FullMatch` −23 to −28 % and no
  longer allocating; `SubexpIndex` 276 → 4.7 ns
  (b6cc4e3). The binding no longer names the C++ runtime among its link flags (f6bf7ff), which made Apple's
  linker warn on every link.
- **Rust.** `replace` is one search (3cff768): 4.17 → 1.83 µs over 111 KB with a second match at the end;
  `replacen` checks its cap after a replacement. `find_iter`, `captures_iter`, `replace_all` and `split` cross
  the C ABI without building an end sentinel (098b6db): 365 → 232 ns on a short line.
